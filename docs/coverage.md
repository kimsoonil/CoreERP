## 측정 범위와 재현

- Java: JaCoCo 0.8.14, Java 21, 전체 컴파일 클래스 포함(별도 제외 없음). 단위·MockMvc·실제 DB 통합 테스트를 함께 실행합니다. MyBatis XML/SQL 자체의 커버리지 수치는 아닙니다.
- React: Vitest 4.1.12 V8, jsdom, `src/**/*.{ts,tsx}` 전체 포함. 미검사 파일도 0으로 포함합니다. 테스트·테스트 설정·타입 선언만 제외합니다. 실제 브라우저 레이아웃 검증 비율이 아닙니다.
- 로컬 PostgreSQL 18.7의 일회용 `_test` DB, 각 측정을 새 빈 DB에서 시작해 계정 초기 생성 경로까지 같은 조건으로 전후 비교했습니다. 재사용 DB에서 계정 초기 생성이 생략되면 수치가 달라질 수 있습니다. CI는 PostgreSQL 17 Testcontainers에서 다시 검사하고 별도 HTML/XML·V8 보고서를 아티팩트로 저장합니다. CI 원본 아티팩트에서도 Java 라인 84.66%·분기 77.04%, React 라인 42.33%·분기 43.82%로 같은 카운터를 확인했습니다.
